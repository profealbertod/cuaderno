# Aula CAD · Tecnología

Aplicación educativa en español para introducir el diseño asistido por ordenador (CAD).

## Contenido
- Fundamentos CAD: planos 2D, modelos 3D y acotación.
- Modelado: croquis, extrusión, sustracción y diseño paramétrico.
- Herramientas: introducción a Tinkercad y FreeCAD.
- Actividades con lista de aprendizaje y preguntas autocorregibles.

## Uso local
Abre `index.html` en un navegador. La aplicación es estática y no necesita dependencias ni proceso de compilación.

## Publicar con GitHub Pages
1. Entra en **Settings → Pages** en el repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama principal (por ejemplo, `main`) y la carpeta `/(root)`.
4. Guarda y espera a que termine la publicación. GitHub mostrará la URL pública en esa misma sección.
